# Career Dashboard 🚀

A responsive React-based Career Dashboard to track job applications with authentication, theme switching, and analytics.

---

## ✨ Features
- Login system with validation
- Persistent login using localStorage
- Theme switching (Dark / Light / Blue / Purple)
- Job tracking (Add / Edit / Delete / Search)
- Applications overview using charts (Recharts)
- Interview calendar integration
- API-based job updates (mock data)

---

## 🛠 Tech Stack
- React (Vite)
- JavaScript
- CSS
- Recharts
- React Icons
- React Calendar

---

## 📸 Project Highlights
- Modern dashboard UI
- Responsive design (mobile + desktop)
- Local storage persistence
- Interactive charts and calendar
